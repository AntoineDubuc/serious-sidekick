Serious Sidekick — Product Roadmap

Last updated: 2026-06-17  ·  Current version: v1.8.0  ·  Claude Code: v2.1.179

Since the last update, Claude Code shipped a run of features that move things on this list. Three matter most: a new way to rewrite a message right before you see it (the missing piece for our plain-English voice work), the built-in session screen now hands out its data in a form our tools can read (the thing the "one screen" item was waiting on), and Claude Code shipped its own engine for running many agents in parallel. Plus two new, stronger models for free. None of it reshuffles the top four, but several items below are now unblocked or cheaper. Sorted by what the user feels — not what's easiest to build.

Now — the next two months of work

1

One-click install

Now
What it does for the user
Anyone with Claude Code can add Serious Sidekick by typing one command instead of cloning a repo and running a shell script. Updates become one command too. Today the install flow filters out most non-engineers — this opens the door.
What it costs us
Medium-large. Repackage the file layout into the Claude-Code-native plugin format, set up a tiny marketplace, write a migration path for existing users.
Since last update
Got easier — add-ons now load straight from a folder with no marketplace setup, and there's a one-command tool that scaffolds the package. Heads-up: today's installer is broken on Windows — native Windows can't run it at all, and the common workaround (Git Bash) crashes partway through, leaving a half-installed mess. A small fix is a prerequisite before this ships.
2

Finish the voice retrofit

Now
What it does for the user
Today only the research-summary handoff speaks in PM voice. The next phase rewrites the worst chat replies in the other thirteen workflows — the code per-task reports, the plan reveals, the review verdicts, all the status banners — so every reply, not just one, is human-readable.
What it costs us
6-8 hours of edits to the playbooks. Optional follow-on: a small translation worker for the four highest-volume moments (another 5-7 hours).
Since last update
The piece we were waiting for shipped: Claude Code can now rewrite a message right before you see it. If a quick test confirms it reaches the helper agents' output, the optional translation worker drops from ~6 hours of hand-edits to flipping one switch.
3

One screen for all your workflows

Now
What it does for the user
Claude Code now ships a "one screen for every session" view. Right now our workflow-status command lives separately and tells you about your active workflows in a different place. Either we sit on top of the new screen and feed it our workflow info, or our status command starts looking outdated next to it.
What it costs us
Medium. Either pipe our workflow data into the new view, or deprecate our own status command and rely on the built-in.
Since last update
The open question is settled. The built-in session screen now hands out its data in a form our tools can read, so the clean path — our status command feeds the built-in screen instead of competing with it — is buildable today. Recommended first step.
4

Walk-away mode for the code workflow

Now
What it does for the user
Tell the code workflow "fix this bug and don't come back until tests pass." Walk away. Come back to a working fix instead of fifty approval prompts. Today, even for low-risk work, you sit through "Go?" between every phase. This adds an unattended option for runs where you trust the plan.
What it costs us
Medium. Wire the code workflow into Claude Code's new "keep working until condition met" command, with a clean fail-safe that drops back to manual gating if anything goes red.
Since last update
More of the plumbing shipped — a no-prompt auto mode, a safe-troubleshooting switch, and run-in-the-background execution. Claude Code also shipped its own engine for running many agents in parallel, which is a possible second route for this. We'll test which is safer before committing — the gates that catch the AI's fake "done" must keep firing either way.

Soon — next quarter, depends on Anthropic shipping

# What we ship What it does for the user What we're waiting on
5 Quick-skills (two-step recipes) Light-weight skills for the operational work between builds: ingest a video and discuss it, audit your workflows for stuck items, check your skills for inconsistencies. Three steps, no full ceremony. Nothing — Anthropic shipped the underlying capability. Effort dropped from a week to two days. Bumped down only because items 1-4 hit more pain.
6 Skills that only load when relevant Some skills load on every session even when they're irrelevant. Anthropic is expected to add a way to scope skills to file patterns ("only load this when I'm editing TypeScript"). Smaller context, faster sessions. Still not shipped as of this update. Related things landed (smarter folder precedence), but the exact "only load this for these files" control isn't here yet. Still waiting.
7 Catch stale plans automatically If you write research on Monday, plan on Tuesday, and someone edits the research file Wednesday before you code, today nothing warns you. This adds a one-line warning when the source has shifted under a downstream plan. No dedicated file-change alert yet — but a new end-of-session checkpoint could power a rougher version of this. Worth a quick feasibility test instead of just waiting.
8 Safe unattended mode for risky operations Headless runs today are all-or-nothing — either nothing prompts and dangerous ops fly through, or every prompt blocks the run. This adds a middle path: dangerous operations pause, harmless denials auto-retry. The exact two controls aren't here, but several related safety pieces shipped (finer-grained permission rules, a safe-troubleshooting switch). Worth re-scoping this around what actually landed.
